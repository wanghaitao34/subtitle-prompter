# 字幕提词器

一个 macOS 小应用：打开视频后自动匹配同名 SRT 字幕，像音乐播放器的歌词一样滚动显示，当前句按时间做卡拉 OK 式变绿，方便对着字幕念、后期配音。可以镜像后放到提词器上用。

![图标](图标方案/AppIcon_1024.png)

## 编译

只需要 Xcode Command Line Tools，不需要 Xcode：

```bash
./build.sh
```

会在当前目录生成 `字幕提词器.app`。要求 macOS 14 及以上（Apple 芯片）。

## 使用

**放入视频**
- 把视频拖进窗口，或按 ⌘O 选文件。
- 自动找同名 SRT：先找同一文件夹，再找旁边的「粗剪字幕 / 成品字幕」；名字对不上时按「02_19」这样的编号前缀匹配。
- 没找到时按 ⌘⇧O 手动选 SRT。也可以只拖一个 SRT，不放视频，按字幕时间轴空跑。

**看字幕**
- 当前句居中放大，文字从左到右按时间变绿。
- 太长的句子自动拆成两行（优先在标点后、按词断开），绿色先填第一行再填第二行。
- 两句之间停顿超过 1 秒，会显示一根横条，长度和停顿时长成正比；3 秒以上的停顿还会写「停顿 N 秒」。停顿中横条从右往左缩短，最后 1 秒变绿。
- 点任意一句跳到那句开头。

**快捷键**

| 按键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 上一句 / 下一句（提前 1 秒） |
| M | 镜像（上下翻转，用于提词器玻璃） |
| F | 全屏 |
| ⌘O / ⌘⇧O | 打开视频或字幕 / 更换字幕 |

右上角还有倍速（0.5×–1.5×）、原声静音、字号大小。字号和镜像开关会记住。

**放到提词器上**
1. 控制中心 →「屏幕镜像」，选 iPad，用随航把 iPad 当第二块屏幕。
2. 把窗口拖到 iPad 上，按 F 全屏、M 镜像。
3. iPad 平放、屏幕顶部朝外，玻璃里看到的字就是正的。

## 图标

图标用 Canva 生成，原图和四个备选方案在 `图标方案/`。换图标：

```bash
swift make_icon.swift 原图.png 图标方案/AppIcon_1024.png
```

再按 `build.sh` 前的步骤用 `sips` + `iconutil` 生成 `AppIcon.icns`，重新编译即可。
